# Amazon Sales Analysis

## Project Overview
This project analyzes Amazon sales data using Python, Pandas, Matplotlib, and Seaborn. It explores sales trends, order categories, fulfilment types, customer locations, product sizes, and order status.

## Technologies Used
- Python
- Jupyter Notebook
- Pandas
- Matplotlib
- Seaborn

## Analysis Performed
- Data cleaning and handling missing values
- Sales analysis by product category
- Order distribution by size and status
- Fulfilment type and sales channel analysis
- Sales analysis by state and city
- Monthly sales trends
- B2B versus non-B2B sales
- Category and size comparisons using visualizations

## Files
- `Amazon Sales.ipynb` — Jupyter Notebook containing the analysis.
- `Amazon Sale Report.csv` — Dataset required to run the notebook, if included.

## How to Run
1. Download or clone this repository.
2. Install the required Python libraries:
   `pip install pandas matplotlib seaborn jupyter`
3. Place the dataset in the same folder as the notebook.
4. Open `Amazon Sales.ipynb` in Jupyter Notebook or VS Code.
5. Run the cells in order.
